# friction

- 資材断面: `b64629a68fab293f6674f1383963014557de1062`

## 事象一覧

- **[出力ずれ]**
  - 事象: 権限設計の比較表を「メリット / デメリット」の自由記述列で提示し、ユーザーから比較観点を軸にした表への作り直しを依頼された。
  - 原因と対策案: 設計案を比較提示する際は、メリット・デメリットの箇条書きではなく、安全性・責務分離・コスト等の比較観点を軸に整理した表を最初から出す。
- **[品質不足]**
  - 事象: コマンド定義（`wrap-up.md` / `improve-yourself.md`）に `executor` という可変のサブエージェント名を直接書き込む設計にしてしまい、`chief.body.md` 側へ委譲責務を閉じるべきとの軌道修正を受けた。
  - 原因と対策案: `commands/` 配下の手順書には具体的なサブエージェント名をハードコードせず、ルーティングや委譲先の解決は `chief.body.md` 側へ閉じ込める。
- **[確認不足]**
  - 事象: ユーザーによるツール実行中断後、ファイル実体を確認せずに直前のサブエージェント報告を信じて「編集・再ビルドは完了している」と誤って報告した。
  - 原因と対策案: 実行中断や例外が発生した後は過去の実行報告を鵜呑みにせず、`git status` や対象ファイルの読み込みで実態を確認してから状況を報告する。
