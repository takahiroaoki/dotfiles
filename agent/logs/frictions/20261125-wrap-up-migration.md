# friction

- 資材断面: `c9930051bf225f3424b9ebba6f043fc2e6204aa5`

## 事象一覧

- **[ルーティング]**
  - 事象: OpenCode V2 の権限仕様や Server Plugin の長文公式ドキュメント読解を `researcher` へ委譲せず、`chief` 自身が `webfetch` してコンテキストを大量消費した。
  - 原因と対策案: 外部ドキュメントの複数ページ読解や仕様調査が必要な時点で、`chief` の自己完結範囲を超えていると判断し `researcher` へ委譲する。
- **[確認不足]**
  - 事象: 既存ログ項目「資材断面」が他ファイルで未参照という理由だけで廃止推奨を提示し、複数端末での並行改善という導入意図を見落として追加往復が発生した。
  - 原因と対策案: 既存の独自仕様や設定項目の廃止を提案する際は、見た目上の未参照だけで推奨を決めず、想定ユースケースや導入背景を確認する前提で中立的に選択肢を示す。
- **[制約・環境]**
  - 事象: `~/dotfiles` を作業ディレクトリにして `/wrap-up` を実行した際、`chief` の `edit: "~/dotfiles/agent/*"` が Location 相対パス `agent/...` に一致せず `Permission denied: edit` になった。
  - 原因と対策案: `~/dotfiles` 内外どちらからでも `agent/` 配下を編集できるよう、プロジェクト設定（`.opencode/opencode.jsonc`）または `executor` 委譲の権限設計を整備する。
