# Architecture Decision Guide

## 1. 基本原則

- **トレードオフ第一法則:** すべてはトレードオフ。性能、セキュリティ、整合性、可用性、再利用性、疎結合の衝突を比較し、Least Worst Architectureを選ぶ。
- **Whyの第二法則:** Howより決定の文脈、理由、代替案、却下理由、再検討条件をADRに残す。
- データシステムは **信頼性**（障害・バグ・誤操作でも正しく動く）、**スケーラビリティ**（負荷増大でも目標レイテンシ等を保つ）、**保守性**（運用性・単純性・進化容易性）の三柱で評価する。

## 2. -ilities と適合度

1. ユーザー価値、失敗時の損失、予測負荷、運用体制から特性を抽出する。
2. 各特性をSLO、上限、測定方法へ翻訳し、必須／重要／対象外に絞る。全部盛りはバサ号であり、コストと複雑性を増やす。
3. 例: 循環依存禁止、レイヤー方向、許容結合度、応答時間、エラー率を適合度関数としてCIや定期検証で測る。構造劣化を検知したら原因と例外を記録し、無制限の抑制で隠さない。

## 3. 分割と内部構造

- **ドメイン分割:** 業務ワークフロー／境界づけられたコンテキスト／変更単位で分ける。機能変更を局所化し、モジュラーモノリスからの移行にも向く。
- **技術分割:** UI、業務、永続化のレイヤー。初期コストは低いが一機能の変更が横断的になりやすい。必要ならドメイン境界をレイヤー内でも保つ。
- DBテーブル（名詞）ごとのCRUDマネージャ化はエンティティ・トラップ。Actor/Actionと不変条件、ワークフローで責務を置く。
- **静的コナーセンス:** 名前(CoN) < 型(CoT) < 意味・定数(CoM) < 位置(CoP) < アルゴリズム(CoA)。強い結合を名前付き定数や型、契約へ弱める。
- **動的コナーセンス:** 実行順序(CoE)、タイミング(CoT)、共有同一性(CoI)など。同期呼出しの連鎖や共有状態を境界で減らす。
- **局所性:** 物理・論理的に遠いほど、強い形式の結合を避け、契約・メッセージ・安定したIDを使う。
- **クアンタム:** 高凝集・同期的コナーセンスを持つ独立デプロイ成果物。要求特性が一組なら単一クアンタム（モノリス／モジュラーモノリス）、異なるスケール・可用性・デプロイ要求が明確なら複数を選ぶ。

## 4. データとフロー

- **SoRと派生:** SoRは唯一の真実と所有権を持つ。検索インデックス、キャッシュ、分析ビューは派生データで、再構築可能な更新経路と鮮度を明示する。
- 2つのストアへアプリから直接書くDual Writesは禁止。SoRのコミット後にCDC（WAL/Binlog）または信頼できるイベントで派生先へ伝播する。イベントソーシングは履歴が業務の真実になる場合に限定する。
- CQRSは書き込みモデルと読み取りビューの要件が異なるときの選択肢で、導入時は投影遅延・再構築・運用コストを受け入れる。
- 2PC/XAは障害連鎖と可用性低下を招きやすい。トランザクション境界を見直し、補償や再試行とエンドツーエンド冪等性（リクエストID、重複排除、順序・期限）で扱う。
- 非同期レプリケーションでは次を要件化する: **Read-after-write**（自分の更新を読む）、**Monotonic Reads**（時点が後戻りしない）、**Consistent Prefix Reads**（因果順序を崩さない）。保証不能ならUI/APIに鮮度を示す。

## 5. 通信とスタイル

- **同期デフォルト:** REST/gRPCは推論、デバッグ、エラー返却が容易。ただし呼出先の遅延・可用性・実行順序に動的結合する。
- **非同期の例外:** キュー／パーティションログは負荷差の吸収、独立スケール、疎結合、障害局所化が必要なときだけ使う。永続化、Ack、再試行、DLQ、重複排除、順序、観測性を必須設計とする。
- **レイヤード:** 単純・低コストで未知の要件に向くが、横断変更とスケール限界に注意。
- **マイクロカーネル:** 安定したコアと交換可能な拡張ルール／プラグインが明確な業務に向く。
- **イベント駆動:** 高スループット・疎結合が価値になる場合。消失防止と再処理を設計し、最終的整合性を利用者へ伝える。
- **マイクロサービス:** 独立デプロイ、異なる特性、チーム境界が投資を正当化する場合のみ。ネットワーク遅延、部分障害、タイムアウト、発見、認証、観測、データ分散というコストを支払う。
- 分散ではメッセージ消失を前提にせず、耐久キュー、送信側コミット、Ack、再送、冪等な消費、監視と復旧手順を確認する。
